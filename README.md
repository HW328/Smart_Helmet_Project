# mining‑smart‑helmet
**多模态矿用全维智安帽系统 | Multimodal Intelligent Safety Helmet System for Mining**
## 📖 项目简介
我国矿山井下普遍存在瓦斯泄漏、塌方跌倒、通信盲区等风险，传统安全帽只具备物理防护；市面多数智能头盔高度依赖4G/Wi‑Fi，井下弱网/无网环境直接失效，报警延迟高。

本项目以 **STM32F407ZGT6** 为主控，构建**环境‑人员‑位置三位一体安全防护体系**，解决矿井信号衰减、报警滞后、无网定位缺失等痛点，实现井下危险实时监测、快速报警与智能监管闭环，为井下作业人员提供轻量化、低功耗、高可靠性智能防护装备。

## ✨ 核心创新点
1. **无网定位创新**：GPS + 高频RFID双模式定位，无网巷道实现 ±3m 人员定位与轨迹追踪，解决井下定位失效。
2. **远距离通信创新**：LoRa远距离透传模块，井下可靠传输距离 ≥1km，穿墙能力强，适配弱网/无网矿井环境。
3. **五级联动报警系统**：本地声光报警、短信远程报警、蓝牙帽间联动、AI大屏弹窗报警、离线语音提示；单帽报警5秒内同步周边矿工。
4. **AI矿工助手Agent**：基于Qwen3基座，结合LoRA微调、NL2SQL，构建矿山领域专属大模型；支持自然语言问答、风险研判、应急辅助决策。
5. **光学图像智能分析**：搭载高清摄像头，完成井下场景识别、危险画面存储；拥有专利：**一种图像数据分析存储系统**。

## 🛠 硬件架构
### 主控
- STM32F407ZGT6

### 感知层模块
- 甲烷气体传感器
- DHT22 温湿度传感器
- 震动+倾斜传感器（跌倒、撞击检测）
- GPS模块
- 高频RFID定位模块（RS485转TTL）
- 井下高清光学摄像头

### 通信模块
- LoRa远距离无线传输
- Air‑780e 4G模块（短信报警、数据上传）
- 蓝牙模块（帽间设备联动）

### 交互与电源
- ASRPRO 离线语音交互模块（无网语音播报、语音控制）
- OLED显示、蜂鸣器声光报警
- 矿用安全锂电池供电

## 💻 软件架构
整体五层物联网架构：`感知层 → 传输层 → 控制层 → 数据分析层 → 智能响应层`

1. **嵌入式端（头盔固件）**
    - 开发环境：Keil‑MDK
    - 语言：C语言，RTOS任务调度
    - 功能：传感器采集、多协议通信、跌倒判断、本地报警、离线语音、蓝牙广播联动

2. **地面监管平台（PC端大屏）**
    - Python + JavaScript开发
    - Qwen3大模型LoRA微调、NL2SQL自然语言数据库查询
    - 功能：人员位置可视化、环境数据展示、报警弹窗、AI矿工助手对话、图像存储与回看

## 📋 完整功能列表
- ✅ 井下环境监测：甲烷瓦斯、温湿度实时采集，超标本地预警
- ✅ 人员状态监测：跌倒、撞击异常自动识别报警
- ✅ **GPS+RFID双模式定位**：有网GPS，无网RFID，全程人员轨迹追踪
- ✅ 多模异构通信：LoRa / 4G / 蓝牙 / RFID‑RS485，保障井下‑地面数据互通
- ✅ 离线语音交互：断网状态语音控制、报警播报、信息查询
- ✅ 蓝牙帽间联动报警：危险事件广播至周边全部安全帽
- ✅ 4G短信远程报警：自动向管理人员推送险情短信
- ✅ 光学摄像头AI分析：井下画面采集，危险画面存储
- ✅ AI可视化监控大屏：人员、环境、报警信息可视化，救援辅助决策
- ✅ AI矿工助手Agent：矿山知识库问答、风险等级研判、应急决策支持
